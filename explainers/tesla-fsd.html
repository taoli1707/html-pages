How does Tesla FSD convert camera images into steering and acceleration commands, quickly and correctly?

Written 2026-09-29 · Reading time: about 30 minutes · You need to know: what a program is, and that a neural network is a function that learns from examples

The short answer

FSD (Full Self-Driving) uses cameras as its only sensors for driving. A car has 7 or 8 cameras, and each camera delivers about 36 images per second.

The design that Tesla published in 2021 and 2022 has 3 stages. Perception converts the images into one 3D description of the road. The planner chooses a path every 50 ms. The controller produces the commands for steering and acceleration.

The design since version 12 (2024) is one neural network. The input is the camera video. The output is 2 values: the next steering and the next acceleration. The network learned from millions of video clips of human driving.

Fast: one perception network needs about 10 ms on the computer of the car. Correct: this is not proven. The driver is responsible at all times, and the US road safety agency investigates FSD in 2 open cases.

Part A: the published design of 2021 and 2022

The short answer for part A

The system is a chain, and each stage reduces the amount of data. Millions of pixel values become a 3D description. The 3D description becomes one path. The path becomes 2 commands.

1. At 50 km/h, the car receives a new image every 0.39 m

Tesla presented this design at two public events: AI Day on 19 August 2021, and AI Day on 30 September 2022. The example uses the times from these events. The speed of 50 km/h is an example value. The example needs one term. The planner is the program that chooses the path of the car.

Worked example: one cycle of the system at 50 km/h
  1. Speed: 50 km/h ÷ 3.6 = 13.89 m/s. 1 m/s is 3.6 km/h. All times of the system are in fractions of a second, so you need metres per second.
  2. Time between 2 images: 1,000 ms ÷ 36 = 27.8 ms. Each camera delivers about 36 images per second.
  3. Distance between 2 images: 13.89 m/s × 0.0278 s = 0.39 m. Distance is speed multiplied by time.
  4. Distance during one run of a perception network: 13.89 m/s × 0.010 s = 0.14 m. Tesla stated about 10 ms for one run of the network that describes the 3D space.
  5. Distance between 2 decisions of the planner: 13.89 m/s × 0.050 s = 0.69 m. Tesla stated that the planner must decide every 50 ms.

Result: at 50 km/h, the description of the road is renewed every 0.39 m, and the plan every 0.69 m.

2. Capture: the network receives raw sensor values

All calculations run on a computer in the car. The main tool is the neural network. A neural network is a function with millions of adjustable numbers, which are named parameters. Training sets the parameters, so that the function gives the wanted output for many example inputs.

A camera of the hardware generation HW3 delivers images of 1280 × 960 pixels. Each pixel value has 12 bits. So one pixel has 4,096 possible levels of brightness.

A normal camera sends its data through an image signal processor (ISP). An image signal processor is a circuit that makes the picture pleasant for a human eye. It also reduces each value to 8 bits, which means 256 levels. Tesla removed this step in 2022. The network receives the 12-bit values directly. Tesla names them "photon counts".

  • More information: 4,096 ÷ 256 = 16 times more levels. This helps in strong sunlight and at night.
  • Less time: the image signal processor needed about 1.6 ms for each camera. For 8 cameras, this is about 13 ms.

Tesla removed the radar from new cars in May 2021, and the ultrasonic sensors from October 2022.

3. Perception: 8 images become one 3D description

An image is flat. Driving needs positions in space: where is the lane, where is the other car, how fast does it move. Perception performs this conversion in 5 steps. With the cameras as step 1, these are the steps 2 to 6 of the complete chain.

Step 2, rectification. Each camera is mounted with a small error of position and angle. This step converts each image to the view of one standard virtual camera. So the network sees the same geometry in every car.

Step 3, backbone. A feature is a number that the network calculates from a region of the image. It describes a property of the region, for example "an edge" or "a part of a wheel". The backbone is the first part of the network, which calculates the features. Tesla used a network type with the name RegNet. A second network type, BiFPN, combines the features of small and large image regions.

Step 4, transformer. A transformer is a network type in which each output position selects the input data that it needs. This selection is named attention.

The output of step 4 is the BEV. The BEV is a map of the surroundings as seen from above, with the car in the centre. BEV is the short form of bird's-eye view. Tesla also names it "vector space". Each cell of the map asks all 8 images: "which features belong to my position?"

Tesla gave the reason for this step. Before, each camera had its own detection, and C++ code joined the results. This failed for a large vehicle near the car, because it appears in up to 5 of the 8 cameras. No single camera sees all of it.

Step 5, video module. The video module is the part of the network that stores features of earlier moments. It stores one set every 27 ms, and one set after each fixed distance. So a car that is hidden behind a truck for a short time stays in the description.

Step 6, output heads. An output head is a small network that produces one kind of result. Tesla described 3 main results in 2022:

  • The occupancy network divides the space around the car into small cubes. One cube is a voxel, which is the 3D form of a pixel. For each voxel, the network gives the probability that an object fills it. It also gives the motion of the voxel. The network needs no name for the object. So it also sees an object of an unknown kind.
  • The lanes network writes the lanes as a graph, point after point. It works in the way a language model writes a sentence, word after word.
  • The objects network gives the moving objects, each with position, speed, and acceleration.

4. Planning and control: one trajectory every 50 ms

A trajectory is a path with time: the position, the speed, and the acceleration of the car for each moment of the next seconds. The planner chooses one trajectory. In 2021, Tesla stated a planning period of the next 10 to 15 seconds.

The planner of 2022 worked in 3 steps.

  1. Create candidates. The planner starts from the lanes, the occupancy, and the moving objects. It creates several possible trajectories. For each one, it predicts how the other road users react. Tesla names this method "interaction search". It is a tree search: each choice opens a branch with the next choices.
  2. Score each candidate. The score has 4 terms: a collision check, a comfort analysis, the probability that a human driver intervenes, and the similarity to human driving. Neural networks calculate the last 2 terms.
  3. Choose the best candidate. The planner sends this trajectory to the last stage.

The controller is the program that converts the trajectory into commands for the steering, the brakes, and the motor. It measures the difference between the planned motion and the real motion, and it corrects this difference.

Why the planner also needs neural networks. A classical calculation of one candidate needed 1 to 5 ms. In 50 ms, this gives 10 to 50 candidates. A small neural network needed about 0.1 ms for the same task. In 50 ms, this gives at most 500 candidates. These are upper limits, because the planner also does other work in the 50 ms.

5. Check your understanding of part A

Try to answer before you open each answer.
  1. A car drives at 100 km/h. How far does it move between 2 camera images?
    Show the answer

    0.77 m.

    100 km/h ÷ 3.6 = 27.78 m/s. The time between 2 images is 1,000 ms ÷ 36 = 27.8 ms. So the distance is 27.78 × 0.0278 = 0.77 m. The typical wrong answer uses the 50 ms of the planner and gives 1.39 m.

  2. Why does the occupancy network see an object of an unknown kind, for example a fallen tree?
    Show the answer

    Because it answers only one question for each voxel: is this space filled?

    It does not need the name of the object. A network that detects only known classes, for example "car" or "pedestrian", has no class for the tree. The typical wrong answer is "because it has seen all kinds of objects in training".

Part B: the end-to-end design since version 12

The short answer for part B

Since version 12, one neural network performs perception, planning, and a large part of control together. Nobody writes the driving rules. The network learns the behaviour from video clips of human drivers, and Tesla selects these clips.

6. About 1.5 billion input values become 2 output values

Ashok Elluswamy leads the FSD software at Tesla. In October 2025 he published the size of the problem. The example follows his numbers.

Worked example: the size of the input and of the output
  1. Pixels per second: 7 cameras × 36 images × 5,000,000 pixels = 1,260,000,000. The current cameras have about 5 megapixels. Elluswamy counts 7 cameras.
  2. Pixels in the memory of the network: 1,260,000,000 × 30 s = 37,800,000,000. The network uses the video of the last 30 seconds, because driving needs the recent past.
  3. Input tokens: 37,800,000,000 ÷ 25 = 1,512,000,000, which is about 1.5 billion. The network does not read single pixels. It reads squares of 5 × 5 = 25 pixels. One such unit of input is a token.
  4. Output: 2 values, the next steering and the next acceleration. These 2 values are sufficient to move the car.

Result: the network reduces about 1.5 billion values to 2 values. Elluswamy states "around 2 billion", because he adds the navigation map and the motion data of the car.

7. One network replaces the 3 stages, and it learns by imitation

An end-to-end neural network is one network from the first input to the last output. Training adjusts all its parameters together, for one goal: the correct driving command.

Imitation learning is a training method in which the network learns to copy the actions of an expert. Here the expert is a human driver. For each moment of a video clip, the network receives the video and predicts the command. Training reduces the difference between this prediction and the action of the human driver.

Design of 2022

Engineers define what passes between the stages: lanes, occupancy, objects.

Engineers write the scoring rules of the planner in C++.

An error is visible at the border between 2 stages.

End-to-end design

The network decides by itself what it passes from one layer to the next.

The behaviour comes from the training data.

An error has no visible place. Tesla adds extra outputs to inspect the network.

The principle: the design of 2022 can only pass what the engineers defined. Chickens that want to cross the road and geese that stay at the side need different reactions. A list of object classes cannot express this intention. An end-to-end network can pass it, because it is not limited to a list.

Tesla states 2 more reasons. Human values are difficult to write as code. And one network has a constant run time.

Elluswamy also writes that other companies do not all agree with this approach.

8. Training selects the data, and a simulator tests the result

The network copies what it sees. Therefore the selection of the data decides the quality. Tesla describes 6 tools.

The 6 tools that Tesla uses to train and to test the network

Imitation learning cannot be better than its examples. Reinforcement learning can find behaviour that is better than the human examples.

9. Wrong idea corrected: the current system has no list of driving rules

Common wrong idea

Wrong: "The system first recognises and names every object. Then a list of rules decides: if the light is red, stop."

Correct: in the current design, recognition and decision are not separate programs. One network converts the video into commands. The behaviour at a red light comes from many clips in which human drivers stopped.

Why the wrong idea fails: it describes the older design. Tesla stated that version 12 replaced over 300,000 lines of C++ code for driving on city streets. Two limits apply. The statement is about city streets, and highways followed later. And program code remains around the network: the release notes of version 13 name a "redesigned controller".

    Show the answer

Part C: fast and correct

The short answer for part C

Speed comes from a computer made for neural networks, and from the removal of steps. Tesla did not publish the total reaction time. Tesla reports 5.3 million miles per major collision with FSD active. This number includes the corrections of the human driver.

11. Fast: each network needs about 10 ms

The photon-to-control latency is the reaction time of the complete system. It starts when light reaches the camera. It ends when the command reaches the steering, the brakes, or the motor. Tesla measures this time, but it did not publish its value. It published the parts in the table.

The computer. The computer of 2019, with the name HW3, contains 2 chips that Tesla designed. Each chip has 2 accelerators for neural networks. One accelerator performs 36 trillion (36,000,000,000,000) operations per second. So the 4 accelerators together perform 144 trillion operations per second. The computer used 72 W in measured driving. The 2 chips also give redundancy: when one chip fails, the other chip continues.

The current computer, AI4, has been in new cars since 2023. Tesla did not publish its number of operations per second.

12. Correct: the numbers of Tesla, and their limits

Tesla publishes a safety report. A major collision in this report is a collision in which an airbag or a similar device deployed.

Two ratios from the same numbers. Against the US average: 5,300,676 ÷ 660,164 = 8.0. Against manual driving in a Tesla with active safety: 5,300,676 ÷ 2,175,763 = 2.4. The second comparison uses the same cars and the same kind of owners. So it is the more equal comparison.

Four limits of these numbers.

  1. The driver corrects the system. FSD has the full name FSD (Supervised). It is a system of SAE Level 2. SAE is the engineering organisation that defined 6 levels of driving automation, from 0 to 5. At Level 2, the system steers and accelerates, and the human driver is responsible at all times. So the number measures the system and the driver together.
  2. Tesla measures its own product. No independent organisation confirmed the numbers.
  3. The US average is an estimate by Tesla. Tesla writes that its method needs assumptions, and that the average can be higher or lower.
  4. Tesla does not judge who caused a collision.

A camera in the cabin observes the driver. This driver monitoring system checks that the driver looks at the road. After several warnings, it stops FSD for the remainder of the trip.

Case EA26002 shows a weak point of a system with cameras only. The agency wrote that the system did not detect that the cameras saw badly, or it warned the driver only directly before the crash. In each of the 9 crashes, FSD lost or never detected the vehicle in front.

Without a driver. Tesla operates a separate taxi service with the name Robotaxi. Since 22 January 2026, a part of its cars in Austin, Texas, drives without an employee inside.

14. Limits of this page

Limits
  • The inside of the current network is not public. Nobody outside Tesla knows if it still contains the steps of part A. Tesla states only that the network can produce such results as extra outputs.
  • The total reaction time is not public. The same is true for the rate of the commands to the steering, the brakes, and the motor.
  • The subject changes fast. The newest version that I found is 14.3.10, of September 2026. The state of case PE25012 after February 2026 is not verified.

15. Recap, glossary, and sources

Recap
  1. Capture: 7 or 8 cameras, about 36 images per second, raw 12-bit sensor values.
  2. Design of 2022: perception, then a planner with a period of 50 ms, then a controller.
  3. Design since version 12: one end-to-end neural network reduces about 1.5 billion input values to 2 output values.
  4. The network learns by imitation of selected human drivers.
  5. Each perception network needs about 10 ms. The total reaction time is not published.
  6. FSD (Supervised) is SAE Level 2. The safety numbers include the human driver, and 2 investigations are open.

Glossary

Backbone (主干网络)
The first part of a neural network, which calculates the features of an image.
BEV, bird's-eye view (鸟瞰图)
A map of the surroundings as seen from above, with the car in the centre.
Controller (控制器)
The program that converts a trajectory into commands for the steering, the brakes, and the motor.
Data engine (数据引擎)
The repeated process that finds failures, collects similar clips from customer cars, and trains again.
Driver monitoring system (驾驶员监控系统)
The camera and the software that check the attention of the driver.
End-to-end neural network (端到端神经网络)
One network from the first input to the last output, trained as one unit.
Feature (特征)
A number that the network calculates from a region of the image, and that describes a property of the region.
Image signal processor, ISP (图像信号处理器)
A circuit that converts raw sensor values into a picture for a human eye.
Imitation learning (模仿学习)
A training method in which the network learns to copy the actions of an expert.
Neural network (神经网络)
A function with many adjustable parameters, which training sets from examples.
Occupancy network (占用网络)
A network that gives, for each voxel, the probability that an object fills it.
Photon-to-control latency (光子到控制延迟)
The time from the light at the camera to the command at the steering, the brakes, or the motor.
Planner (规划器)
The program that chooses one trajectory.
Reinforcement learning (强化学习)
A training method in which the network receives a score for the result of its actions.
SAE Level 2 (L2 级辅助驾驶)
The level of automation at which the system steers and accelerates, and the human driver is responsible at all times.
Shadow mode (影子模式)
A test in which a new network runs in customer cars without control of the car.
Token (词元)
One unit of input or output of a network, for example a square of 5 × 5 pixels.
Trajectory (轨迹)
A path with time: position, speed, and acceleration for each moment of the next seconds.
Transformer (Transformer 模型)
A network type in which each output position selects the input data that it needs. The selection is named attention (注意力机制).
Tree search (树搜索)
A search in which each choice opens a branch with the next choices.
Video module (视频模块)
The part of the network that stores features of earlier moments.
Voxel (体素)
A small cube of space. It is the 3D form of a pixel.
World simulator (世界模拟器)
A neural network that generates the video which the cameras would see after each command.
